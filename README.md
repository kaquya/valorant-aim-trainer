# Valorant Aim Trainer

A browser-based sensitivity finder and aim trainer inspired by Valorant aiming fundamentals.

## Features

- DPI-based Valorant sensitivity calculation
- Sensitivity assessment flow
- Browser-based aim training
- Optional mousepad size input
- Settings page for sensitivity and training preferences
- Local-first data storage

## Tech Stack

- Vite
- React
- TypeScript
- HTML Canvas
- CSS
- Vercel

## Project Status

Early development.
